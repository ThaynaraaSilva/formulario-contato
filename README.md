# Formulário de Contato

> Formulário de contato responsivo desenvolvido com HTML, CSS e JavaScript, com integração ao Formspree para envio de mensagens.

---

## Sobre o projeto

Este projeto foi desenvolvido como prática de desenvolvimento web, com o objetivo de criar um formulário de contato funcional, organizado e responsivo.

A aplicação permite que o usuário informe seu nome, e-mail, assunto e mensagem.

Após o preenchimento, os dados são enviados utilizando o Formspree e o JavaScript apresenta uma mensagem informando o resultado da operação.

---

## Preview

### Página do formulário

O projeto possui uma interface simples contendo:

- Nome
- E-mail
- Assunto
- Mensagem
- Botão de envio
